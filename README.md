# Qeth

Local tools for document quality, agent traces, bounded web crawling, and offline survey planning.

## Install

Requires Node.js **22.18 or newer**. The public npm release is being prepared. Until it is published, use the source instructions below.

After publication:

```sh
npm install -g qeth
qeth --help
```

The four basic commands work without an account, a model download, or a paid API key. Documents and traces stay on your machine. The crawler contacts only the site you select.

## Four commands

### Check document chunks

```sh
qeth rag scan ./docs
qeth rag scan examples/chunks.json --json
```

Scan text, Markdown, JSON, or JSONL. Find repeated content, repeated IDs, missing metadata, invalid records, and inconsistent supplied embeddings. Plain text is chunked locally. Qeth does not generate embeddings or claim to measure hallucination probability.

Hidden files, links, and dependency/build folders are excluded. Scans have file, byte, and traversal limits.

### Inspect an agent run

```sh
qeth trace examples/trace.json
qeth trace examples/trace.json --baseline examples/baseline.json --json
```

Inspect failures, elapsed time, overlapping event durations, and supplied token usage. Missing token data remains unknown. A baseline comparison is available only when both inputs have complete token totals.

### Crawl a small site

```sh
qeth crawl https://example.com --max-pages 5 --max-depth 1 --json
```

Collect static HTML text and a graph of same-origin pages and links. Qeth checks robots rules, follows bounded redirects, limits requests and response sizes, and stops at a two-minute deadline. It does not run page JavaScript, sign in, extract semantic entities, or create embeddings.

`--max-pages` limits all page request attempts, including redirects. Robots retrieval has its own small redirect bound. A redirect chain can therefore use the request budget before a final HTML page is collected.

Public destinations are allowed by default. Use `--allow-local` only when you intend to test a loopback server. It does not enable private LAN or metadata addresses.

### Plan an offline survey

```sh
qeth mission plan examples/survey-area.geojson --spacing 20 --speed 5
qeth mission plan examples/survey-area.geojson --optimize battery --json
```

Generate survey legs and connectors that stay within a valid small polygon and avoid its holes. The report includes two-dimensional GeoJSON, relative waypoint altitude, route length, time, and a simple battery estimate.

This is an **open, offline route**. Wind, acceleration, takeoff, landing, sensor coverage, hardware limits, and return-to-home are not modeled. Battery and distance modes share the same objective under the constant-speed model. The result is not a globally optimal route or a flight approval.

## Output

```sh
qeth doctor
qeth trace examples/trace.json --json --out run-report.json
```

`--json` prints one versioned JSON report. `--out` writes JSON to a **new** file and refuses to overwrite an existing file. Without that option, commands do not create report files.

| Exit | Meaning |
| --- | --- |
| 0 | Command completed; inspect any reported quality findings |
| 2 | Invalid command or input |
| 1 | Runtime, file, or network failure |

See the [command contract](docs/cli-contract.md) for input formats, options, limits, and report fields. The [captured example session](docs/example-session.md) is generated by running the commands against local fixtures.

## Use as a library

```js
import { scanDocuments, analyzeTrace, planMission, crawlSite } from 'qeth';

const report = await scanDocuments('./docs');
console.log(report.chunkCount);
```

Qeth is an ES module package with TypeScript declarations. The library uses the same rules as the CLI.

## Run from source

```sh
git clone https://github.com/ungaaaabungaaa/qeth.git
cd qeth
npm ci
npm run check
node dist/cli.js --help
npm run demo
npm run smoke:package
```

Tests use controlled inputs and a temporary loopback HTTP server. The package smoke check builds a tarball, installs that exact tarball in a temporary location, runs all four commands, and removes the temporary install.
