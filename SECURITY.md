# Security

## Report a vulnerability

Use the repository's private vulnerability reporting feature when available. Otherwise contact the maintainer at `syed_abdul_muqeeth@proton.me`. Include a minimal reproduction and the affected version. Do not post credentials or private input files in a public issue.

## Boundaries

The basic document and trace commands run locally. Qeth has no telemetry or account system. A crawl sends requests to the selected origin, checks robots, blocks non-public addresses by default, pins validated network destinations, and applies time, size, URL, and request limits. The explicit local option permits loopback fixtures; it does not grant general LAN access.

Review reports before sharing them. They can contain source text, URLs, filenames, IDs, and trace names from your inputs. Mission planning is an offline geometric tool and does not control hardware.

## Supported versions

Fixes target the latest release. This is an early 0.x project. Security reports will be assessed by the maintainer; there is no promised response time. Use the current release notes to assess changes before upgrading.
